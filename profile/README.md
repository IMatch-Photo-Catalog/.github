## How IMatch Sits

IMatch does not replace the camera folder, the editor, or the discs you already own. It sits beside them as a named DAM desk for one job: which files are in the catalog, which keywords still match, and what the next person should read. A local IMatch profile is enough for everyday work.

If two people share a photo desk, each keeps an IMatch style of their own. The live keyword tree stays small on purpose. Extra libraries wait for their own catalog instead of crowding the session.

A first visit should be one short keyword pass, then the same IMatch catalog the next day. That is enough to see if the layout holds.

Metadata without a catalog name is a pile. Keep IMatch metadata workspace tied to the same title as the files.

Write ratings and keywords in IMatch keyword tree before you rename folders. The catalog should still find a shot after the path changes.

## Traffic Light

| Signal | On the IMatch board | What you do |
|--------|----------------------|-------------|
| Green | Named catalog, short live shoot list | Continue the same keyword pass |
| Amber | Two libraries mixed in one tree | Split the set before a large edit |
| Red | No title, no note, keywords unlabeled | Stop and name the catalog first |
| Clear | Handoff written, live shoots few | Close IMatch and leave the DAM desk |
| Hold | Catalog still reading a large import | Wait before you rewrite keywords |
| Stale | Keywords from a retired job still pinned | Drop them from the live IMatch set |
| Split | People and places sharing one branch | Separate the IMatch keyword tree |

## Open Order

1. Open the last IMatch catalog, not a new empty DAM desk.
2. Read the keyword tree and the last handoff.
3. Finish one visible keyword pass inside IMatch.
4. Write what changed, then close with fewer loose shoots than you found.
5. If the set feels crowded, drop anything that belongs to a different IMatch job.
6. Confirm IMatch photo catalog still points at folders you own.
7. Save metadata in IMatch metadata workspace before you leave.
8. Keep versioned keywords on the tree, not only in file names.
9. Leave the catalog title on the desk before you close.

## After a Week

A week in IMatch is not a bigger keyword tree. It is the same title, a shorter live shoot list, and a note that still makes sense on Monday. If every job is pinned, nothing stands out. Take finished shoots off the live set so the next visit starts on pictures that still need keywords.

Other programs stay where they are. IMatch only keeps the path back: catalog name, metadata, keyword tree, handoff.

Leave IMatch with a quieter DAM desk than the one you opened. The next visit should start on that catalog, not in a folder-name hunt.

A keyword that only lives in a folder name will vanish when you move files. Keep it on IMatch photo catalog.

## Field Note

IMatch is easier to trust when the catalog stays smaller than the folder pile it came from. Name the session, keep the live shoots, finish one visible keyword pass, and write what changed. Extra jobs wait for their own title.

The same loop fits a client packet, a home library, or a shared photo desk. Open the last IMatch catalog and continue. Do not rebuild the layout from scratch.

A DAM desk is a map of pictures you own. Leave IMatch pointed at that map, with keywords a second person can read.
